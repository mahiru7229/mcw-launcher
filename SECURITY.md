# Security Policy

## Phạm vi hỗ trợ

Nhánh release mới nhất nhận security fix. Bản alpha là prerelease và không nên dùng làm nơi lưu dữ liệu tài khoản quan trọng nếu chưa có backup.

## Báo cáo lỗ hổng

Không đăng public exploit, access token, account database hoặc diagnostics bundle chưa được kiểm tra. Hãy dùng GitHub Security Advisories của repository để gửi báo cáo riêng tư, kèm:

- phiên bản/commit và nền tảng;
- bước tái hiện tối thiểu;
- tác động dự kiến;
- log đã xóa username, UUID, token và đường dẫn cá nhân.

Không cần truy cập dữ liệu của người khác để chứng minh lỗi. Dự án sẽ xác nhận báo cáo, đánh giá mức độ và phối hợp thời điểm công bố sau khi có bản sửa.
