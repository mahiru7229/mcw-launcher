MCW Launcher v1.5.1-beta.3 delivery

Primary change: Updater Architecture v2

- Dedicated entry point: updater.py
- Dedicated PyInstaller spec: mcw_updater.spec
- Windows package updater: updater/MCW Updater.exe
- Linux package updater: updater/mcw-updater
- mcw-update.json schema: 2
- Manifest field `updater` is mandatory.
- Launcher copies the updater from the INCOMING release ZIP to system temp.
- No fallback to copying/renaming the currently installed launcher executable.
- Update request schema: 2
- Beta 2 executable-first/retry/rollback safety remains in the updater.
- Bridge upgraded to v1.1.0 and pinned to v1.5.1-beta.3.

Release build order:
1. Apply these changed files to the repository.
2. Commit and push.
3. Publish GitHub pre-release tag v1.5.1-beta.3.
4. release.yml builds Launcher + Updater independently for Windows/Linux.
5. release.yml packages schema-2 ZIPs and uploads ZIP + SHA-256 assets.
6. After release assets exist, run "Build MCW Update Bridge" manually.
7. Bridge workflow uploads MCW-Update-Bridge-v1.1.0-windows-x64.exe + .sha256 to the Beta 3 release.
