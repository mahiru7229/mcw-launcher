# MCW Launcher v1.5.1 stable build/test notes

Target GitHub release: `v1.5.1` (not a pre-release).

Stable is promoted from Beta 7. Release-critical additions are the stable version/channel switch and MCW Update Bridge v1.6.0 pinned to v1.5.1.

The bridge is intended as a one-time manual recovery path for users still on v1.5.0 whose legacy updater cannot replace the launcher executable. Beta 3+ installations should use the normal bundled updater. Do not upload `MCW-USE-BRIDGE` for the stable release unless a new emergency issue requires forcing Bridge for newer launchers.
