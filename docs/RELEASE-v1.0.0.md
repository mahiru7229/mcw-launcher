# MCW Launcher v1.0.0

First stable 1.0.0 release.

## Release focus

- First Run Setup with language, updates, Java scan guidance, and runtime defaults.
- Dedicated GPU preference as an opt-in launcher setting.
- Provider-native modpack import and dual export modes.
- Navigation cleanup and content management improvements.
- Translation completion pass and stable user-facing polish.
- Stable public `mcw_core` release published alongside the launcher.
