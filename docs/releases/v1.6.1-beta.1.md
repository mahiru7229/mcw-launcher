# MCW Launcher v1.6.1-beta.1

Bản phát hành Beta 1 của phiên bản 1.6.1 tập trung giải quyết triệt để lỗi tạo instance NeoForge 1.21.1 trên Windows liên quan đến giới hạn độ dài đường dẫn tệp tin (`MAX_PATH = 260` ký tự).

## Các thay đổi chính

1. **Vá lỗi Issue #32 (`FileNotFoundError: [WinError 3]`)**:
   - Khi tạo instance Minecraft 1.21.1 với NeoForge 21.1.251 / 21.1.249, một số thư viện lồng sâu (như Guava `listenablefuture-9999.0-empty-to-avoid-conflict-with-guava.jar` với độ dài 138 ký tự) kết hợp với đường dẫn cài đặt của người dùng khiến tổng độ dài đường dẫn vượt quá giới hạn 260 ký tự của Windows mặc định (`LongPathsEnabled = 0`).
   - Hàm sao chép tệp `shutil.copy2` (`_winapi.CopyFile2`) trước đây không gắn tiền tố `\\?\` dẫn đến lỗi `[WinError 3] The system cannot find the path specified`.

2. **Rút ngắn tên tệp tạm thời trong `SharedFileMaterializer`**:
   - Chuyển đổi định dạng tệp staging publish từ `.{destination_path.name}.{uuid4().hex}.publishing` sang `.tmp_{uuid4().hex[:8]}.pub`.
   - Tiết kiệm tới hơn 90 ký tự trên mọi thao tác nạp thư viện và tệp dùng chung.

3. **Hỗ trợ Extended-Length Path (`\\?\`) toàn diện**:
   - Bổ sung `copy_file`, `link_file`, `same_file` vào `src.core.fs.windows_path`.
   - Tự động gắn tiền tố mở rộng `\\?\` trên Windows để hỗ trợ đường dẫn dài tới 32.767 ký tự.
   - Bổ sung cơ chế fallback sao chép dạng stream từng block buffer nhị phân nếu hàm Win32 API bị từ chối.
   - Cập nhật `NeoForgeVersionManager` và `ForgeVersionManager` sử dụng toàn bộ API tệp an toàn trên đường dẫn dài.

## Test trực tiếp

1. Mở launcher bản v1.6.1-beta.1.
2. Nhấp vào **Tạo Instance**.
3. Chọn Minecraft **1.21.1**, Mod Loader **NeoForge** (bản 21.1.251 hoặc 21.1.249).
4. Nhấp **Tạo** và xác nhận tiến trình tải về, cài đặt và nhập thư viện hoàn tất thành công mà không gặp lỗi `[WinError 3]`.
