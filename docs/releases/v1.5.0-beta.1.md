# MCW Launcher v1.5.0-beta.1

Beta 1 đưa automatic updater Linux x64 vào giai đoạn thử nghiệm. Windows và Linux dùng chung contract release ZIP, SHA-256, manifest, staging, backup và rollback; mỗi nền tảng chỉ nhận đúng asset của mình.

## Điểm chính

- Chọn đúng `MCW-Launcher-v1.5.0-*-linux-x64.zip` trên Linux và `windows-x64.zip` trên Windows.
- Xác minh SHA-256 trước khi giải nén.
- Kiểm tra `mcw-update.json`: schema, version, platform, executable và toàn bộ managed files.
- Chặn path traversal, symlink, duplicate path và file không khai báo trong archive.
- Linux helper chạy tách session, chờ launcher đóng rồi thay file atomically.
- Giữ mode `0755`, tự khởi động lại launcher và rollback nếu cài đặt thất bại.
- Không gọi `sudo`; thư mục cài đặt phải do người dùng hiện tại ghi được.
- Không ghi vào account, instance, world, config hoặc runtime XDG trong quá trình thay launcher.

## Kiểm định trước Beta 2

- Unit test bao phủ asset selection, checksum, manifest và archive security.
- Integration test tạo gói Beta 2 local, chuẩn bị update bằng cache, thay binary Beta 1 giả lập và xác nhận dữ liệu người dùng không đổi.
- Windows updater tiếp tục dùng cùng `UpdateApplier` và release manifest.

## Release gate Beta 1 → Beta 2

Beta 2 sẽ xác nhận luồng thật trên Lubuntu: Beta 1 phát hiện GitHub Release Beta 2, tải ZIP + SHA-256, tự đóng, cập nhật, mở lại với version Beta 2 và giữ nguyên toàn bộ dữ liệu XDG.

## Giới hạn

- Chưa có AppImage hoặc DEB.
- Linux ARM64 chưa hỗ trợ automatic updater.
- Nếu gói Beta 1 đã phát hành có lỗi updater, cần cài Beta 2 thủ công; updater hỏng không thể tự sửa chính nó.
