# MCW Launcher v1.8.1-beta.3

Bản thử nghiệm **v1.8.1-beta.3** của MCW Launcher tập trung tối ưu hóa trải nghiệm tải mod thủ công từ CurseForge, tự động điều hướng người dùng tới trang chờ tải trực tiếp và loại bỏ nguy cơ tải nhầm phiên bản mod không tương thích.

## Các cải tiến chính trong bản beta.3

### 1. Điều hướng thẳng vào trang đếm ngược tự động tải (`/download/{file_id}`)
- **Loại bỏ nhầm lẫn phiên bản**: Trước đây, khi thiếu CurseForge Gateway API key, người dùng có thể bị chuyển đến trang tìm kiếm hoặc trang chủ mod. Việc nhấn nút "Download" lớn trên trang chủ CurseForge luôn tải về phiên bản mới nhất (MC 1.20/1.21), gây lỗi không tương thích phiên bản (`EarlyLoadingException` / `javafml:40` / `javafml:61`) khi chạy các modpack cũ hơn như 1.16.5.
- **Tự động bắt đầu tải sau 5 giây**: Đường dẫn mở ra từ launcher luôn trỏ thẳng tới trang đếm ngược chính thức:
  `https://www.curseforge.com/minecraft/{category}/{slug}/download/{file_id}`
  Trình duyệt sẽ tự động kích hoạt tải file jar chính xác của modpack mà người dùng không cần phải tìm kiếm hay bấm nút tải thủ công.

### 2. Tự động phân giải slug không cần API Key (`cflookup.com`)
- **Tích hợp bộ tra cứu dự phòng**: Bổ sung bộ phân giải slug dự phòng qua dịch vụ công khai `cflookup.com/{project_id}` kết hợp cache trong bộ nhớ.
- **Xử lý triệt để manifest ID số**: Bất kỳ modpack nào chỉ khai báo `projectId` số đều được phân giải chính xác thành slug chính tắc (ví dụ: `scape-and-run-parasites`, `better-default-biomes`, `harder-branch-mining`) ngay cả khi môi trường chưa cấu hình Gateway API key.

### 3. Nút "Mở tất cả liên kết tải" (`open_all_button`)
- **Tải hàng loạt tiện lợi**: Hộp thoại tải thủ công bổ sung nút **Mở tất cả liên kết tải** khi có từ 2 mod cần nạp trở lên.
- **Tự động nhận diện file tải về**: Trình duyệt mở đồng thời các tab đếm ngược, và tính năng theo dõi thư mục `~/Downloads` của MCW Launcher sẽ tự động phát hiện các file vừa tải, kiểm tra mã băm SHA-1 và nạp ngay vào instance.

### 4. Kế thừa toàn bộ tính năng từ v1.8.1-beta.2
- Khử trùng lặp thư viện Maven (Deduplicate Maven Libraries) trên Classpath, ghi đè an toàn Log4j và lwjgl.
- Khởi chạy trực tiếp theo cơ chế Prism Launcher (không chặn kiểm tra trước).
