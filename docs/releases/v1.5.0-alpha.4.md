# MCW Launcher v1.5.0-alpha.4

Alpha 4 hoàn thiện nền Forge/NeoForge trên Linux và chuẩn hóa responsive UI theo nguyên tắc giữ kích thước tự nhiên của widget.

## Điểm chính

- Forge và NeoForge trở thành Linux release gate.
- Mojang Java metadata được ưu tiên; profile thiếu metadata được fallback sang Java phù hợp theo Minecraft release.
- Managed Java 8, 17, 21 và 25 có thể tồn tại song song; Java 16 metadata dùng compatibility runtime 17.
- Forge-family installer chạy trong process group riêng và dọn child process khi timeout trên POSIX.
- Add Instance, First Run và Instance Settings giữ minimum size; khi nội dung quá cao, thanh cuộn dọc xuất hiện thay vì ép widget co lại.

## Cần xác nhận trên Lubuntu

1. Forge 1.20.1 launch tới menu chính bằng Java Automatic.
2. NeoForge 1.21.1 launch tới menu chính và có thể Stop/Kill sạch.
3. Relaunch dùng lại loader profile, libraries và Java cache.
4. Modrinth modpack Forge hoặc NeoForge có thể cài và launch.
5. Các dialog chính không cắt/chồng nội dung ở độ phân giải thấp.

## Giới hạn

- Chưa có AppImage hoặc DEB.
- Automatic updater vẫn chỉ dành cho Windows packaged build.
- Linux ARM64 và dGPU Linux chưa nằm trong release gate.
- MCW Core độc lập chưa được phát hành trong bước này.
