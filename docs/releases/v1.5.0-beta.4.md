# MCW Launcher v1.5.0-beta.4

Beta 4 sửa regression Open Folder trên Linux phát hiện trong quá trình smoke-test Beta 3.

## Điểm chính

- Làm sạch môi trường PyInstaller trước khi mở chương trình desktop của hệ thống.
- Khôi phục `LD_LIBRARY_PATH_ORIG` và loại các đường dẫn Qt/Python bundle khỏi child process.
- Kiểm tra lỗi sớm của `xdg-open` thay vì coi việc spawn process là đã mở thành công.
- Fallback theo thứ tự `xdg-open` → `gio open` → `pcmanfm-qt` trên Lubuntu.
- Giữ Qt Desktop Services làm fallback cuối trên các nền tảng khác.
- Hiển thị lỗi cùng đường dẫn instance nếu không desktop handler nào nhận thao tác.

## Release gate Beta 4

1. Test suite Windows và Ubuntu đạt.
2. Trong ZIP Linux x64, Open Folder mở đúng thư mục của instance nằm dưới XDG data root.
3. Tên instance và đường dẫn có dấu cách vẫn mở được.
4. Open logs, backups, mod folder và Java folder không bị regression.
5. Cập nhật Beta 3 → Beta 4 giữ nguyên account, instance, runtime và executable mode.

## Giới hạn

- Chưa có AppImage hoặc DEB.
- Linux ARM64 chưa nằm trong release gate.
