# MCW Launcher v1.8.6

Bản phát hành chính thức **MCW Launcher v1.8.6** tổng hợp toàn bộ kết quả nâng cấp, sửa lỗi chuyên sâu và tối ưu hóa hiệu năng trên cả 3 phân hệ Core Engine, Mạng & Content Pipeline, và Giao diện người dùng:

---

## Các tính năng và cải tiến nổi bật trong v1.8.6

### 1. Sửa dứt điểm lỗi Thanh tiến trình bị kẹt đỏ ("in vết") & Hoàn thiện GUI
- **Loại bỏ việc quét ngược lịch sử Task lỗi cũ trong `GlobalTaskIndicator`**:
  - Không còn quét lại danh sách lỗi từ các tác vụ đã kết thúc trước đó trong `TaskQueue`; thanh tiến trình xanh lá 100% của tác vụ mới luôn ghi đè tức thì lên trạng thái lỗi cũ và tự ẩn sau 2.5 giây.
  - Hỗ trợ bấm trực tiếp vào thanh tiến trình để xóa ngay thông báo lỗi.
- **Bảo vệ trạng thái tác vụ chạy chế độ thay thế (`REPLACE`)**:
  - `TaskQueue` tự động bỏ qua các sự kiện kết thúc muộn của thế hệ cũ khi thế hệ mới cùng `task_id` đang hoạt động.
- **Khắc phục lỗi điều khiển Instance & Mod Manager**:
  - Sửa lỗi `NameError` khi buộc dừng game thất bại; bổ sung xử lý lỗi cho toàn bộ tác vụ cài/nhập modpack (`modpack.*`).
  - Hỗ trợ đầy đủ Mod Loader Quilt trong `ModManagerDialog` và hiển thị thông báo cập nhật cho tất cả loader.
  - Kết nối nút "Quản lý nâng cao" trong tab Mods và đồng bộ Registry khi gỡ bỏ mod.
  - Tối ưu `ThemedProgressBar` tự ngắt timer xung nhịp 60 FPS khi đứng yên ở 0% hoặc 100% để tiết kiệm CPU.
  - Bảo toàn thiết lập `forge_preflight_failure_policy` khi lưu cài đặt instance.

### 2. Tối ưu hóa Mạng, CurseForge Official API v1 & Download Pipeline
- **Hoàn thiện kết nối CurseForge Official API v1**:
  - Nhận diện chuẩn xác mã lỗi HTTP (400, 401, 403, 404, 429) và header `Retry-After`; không retry vô ích khi gặp lỗi cố định.
  - Hỗ trợ lọc theo `gameVersion` trực tiếp trên server để không bị giới hạn ở 50 file mới nhất cho các bản Minecraft cũ.
  - Cho phép tìm kiếm mod Fabric cho instance Quilt mà không bị lọc cứng `modLoaderType=5`.
  - Gom các yêu cầu siêu dữ liệu file thành các truy vấn batch 50 file/lần trước khi tải modpack.
- **Tối ưu hóa bộ nhớ đệm (API Cache) & Download**:
  - Loại bỏ hoàn toàn thao tác tính lại dung lượng và ghi đĩa đồng bộ (`os.fsync`) ở mỗi lần đọc cache hit trong `CurseForgeApiCache`, `FTBApiCache` và `ATLauncherApiCache`.
  - Loại bỏ deadlock semaphore trong `DownloadManager` khi chọn file tải thủ công lúc đang tạm dừng tải.
  - Bỏ lượt băm lặp lại khi hit cache tải file và cho phép tải thư viện Maven có `size >= 0`.
  - Sửa lỗi phân trang `FTBClient.search_projects` để mở khóa nút chuyển trang tiếp theo.
  - Tối ưu cập nhật: chỉ fallback sang GitHub khi Cloudflare gặp lỗi mạng; bổ sung cờ `MOVEFILE_COPY_ALLOWED` trong `UpdateApplier` cho Windows.

### 3. Tăng cường khả năng chịu lỗi Core Engine, Khởi chạy & Bảo mật
- **Bảo vệ toàn vẹn luồng khởi chạy Modpack**:
  - `MinecraftExecutor` bảo lưu đầy đủ ngoại lệ tạm dừng tải và yêu cầu file thủ công (`PortableManualDownloadRequired`, `CurseForgeManagedFilesRequired`, `ModrinthManagedFilesRequired`, `RequiredModDependenciesMissing`), kích hoạt đúng hộp thoại hỗ trợ tải thủ công.
- **Bảo vệ an toàn dữ liệu sao lưu (`InstanceBackupManager`)**:
  - Không xóa thư mục `rollback` khi quá trình khôi phục gặp sự cố, đảm bảo dữ liệu thế giới và mod của người dùng không bao giờ bị xóa nhầm.
- **Nhận diện chính xác tiến trình dừng chủ động (`ProcessSupervisor`)**:
  - Tra cứu lịch sử phiên để phân biệt chính xác giữa người dùng bấm dừng game và trường hợp game bị crash thực sự.
- **Tăng tốc quét Modpack lớn (>300 mods)**:
  - Bổ sung bộ nhớ đệm `(path, mtime, size)` cho `ModManager.read_mod`, quét Jar-in-Jar và băm SHA-1, giảm hàng nghìn thao tác mở file ZIP trước khi vào game.
- **Gia cố bảo mật RPC Server & Thực thi Java**:
  - Chặn `Origin: null`, yêu cầu `Content-Type: application/json` và xả luồng dữ liệu unread trên Windows HTTP RPC Server.
  - Kiểm tra tính hợp lệ của tên file thực thi Java trước khi gọi lệnh kiểm tra phiên bản.
  - Khai báo đầy đủ `argtypes`/`restype` 64-bit cho các hàm Win32 API trong `GameWindowActivator`.
