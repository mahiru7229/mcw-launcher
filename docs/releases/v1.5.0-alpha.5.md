# MCW Launcher v1.5.0-alpha.5

Alpha 5 là Alpha cuối của nhánh 1.5.0, tập trung loại bỏ công việc lặp trong launch pipeline và chốt responsive UI trước Beta.

## Điểm chính

- Cảnh báo tương thích tạm dừng launch attempt hiện tại thay vì kết thúc task.
- Chọn cho phép sẽ tiếp tục ngay với dependency graph, loader profile và preflight report đã chuẩn bị.
- Không resolving/checking lại toàn bộ nội dung sau cảnh báo.
- Button trong dialog giữ đủ chiều rộng theo text đã dịch.
- Hàng trạng thái OptiFine trong Add Instance giữ chiều cao và kích thước tự nhiên.

## Release gate

1. Vanilla, Fabric, Quilt, Forge và NeoForge launch/relaunch thành công.
2. Microsoft login và credential persistence đạt trên Windows/Linux.
3. Offline cache launch và process Stop/Kill đạt.
4. Compatibility warning chỉ xuất hiện một lần và tiếp tục cùng launch attempt.
5. Dialog không cắt chữ; màn hình thấp dùng thanh cuộn dọc.
6. GitHub Actions chỉ build Beta/RC/Stable sau khi test Windows và Linux cùng pass.

## Giới hạn

- Chưa có AppImage hoặc DEB.
- Linux ARM64 và dGPU Linux chưa nằm trong release gate 1.5.0.
- MCW Core độc lập chưa được phát hành trong bước này.
