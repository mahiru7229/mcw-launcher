# MCW Launcher v1.5.1-beta.7

Beta 7 focuses only on mod dependency resolution. The updater architecture and Windows executable replacement layer are unchanged from Beta 6.

## Fixed

- Read Fabric Loader `provides` from `fabric.mod.json`.
- Register every provided alias with the same version as the primary Fabric mod ID.
- Make compatibility checks treat a provided alias as installed, including `cloth-config2` provided by Cloth Config API whose primary ID is `cloth-config`.
- Include Fabric aliases in `ModCapabilityIndex` for top-level JARs.
- Include aliases declared by Fabric metadata inside safely scanned nested JARs.
- Validate Modrinth dependency candidates using these aliases so a verified Cloth Config download is no longer rejected after download.

## Regression coverage

- Top-level Fabric `provides` parsing.
- Compatibility resolution through an alias.
- Top-level capability indexing.
- Nested Fabric JAR capability indexing.
- Modrinth dependency discovery for `cloth-config2` when the downloaded project declares `id=cloth-config` and `provides=["cloth-config2"]`.

## Live validation

Re-test the affected modpack and confirm the dependency phase no longer ends with `Dependency 'cloth-config2' ... blocking requirement(s)` after Cloth Config API has been downloaded and verified.
