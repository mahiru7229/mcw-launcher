# MCW Update Bridge v1.3.0

- Targets MCW Launcher `v1.5.1-beta.4`.
- Supports Windows x64 and Linux x64 recovery.
- Applies schema-2 `cleanup_paths`, including removal of obsolete `docs/`.
- Can be invoked automatically by the launcher only when the release carries the explicit `MCW-USE-BRIDGE` maintainer marker.
