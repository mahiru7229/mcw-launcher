# MCW Launcher v1.8.7

Bản phát hành **MCW Launcher v1.8.7** tập trung vào tự động phát hiện và nâng cấp phiên bản Java cho Mod Fabric/Quilt từ bytecode `.class`, xử lý triệt để lỗi giao diện màn hình chờ `StartupSplash`, cùng các tối ưu hóa cơ sở dữ liệu tài khoản, xác thực OAuth và tiến trình RPC:

---

## Các tính năng và cải tiến nổi bật trong v1.8.7

### 1. Tự động phát hiện phiên bản Java từ Bytecode Mod & Tự nâng cấp khi Recovery
- **Quét Bytecode `.class` và Metadata Mod (`JavaMajorPolicy.required_for_instance`)**:
  - Tự động đọc trường `depends.java` trong `fabric.mod.json` / `quilt.mod.json` và header phiên bản class file `.class` của các mod đang bật (kèm bộ nhớ đệm theo `(path, mtime_ns, size)`).
  - Tự động nâng phiên bản Java yêu cầu (ví dụ các mod MC `1.16.1` biên dịch bằng Java 16 `class file version 60.0` sẽ tự chọn Java 17 thay vì lỗi với Java 8).
- **Mở rộng tùy chọn Java cho người dùng (`allow_higher=True`)**:
  - Cho phép người dùng tự chọn bản Java cao hơn (`17`, `21`, `25`) trên các instance `vanilla`, `fabric`, `quilt`.
- **Trích xuất phiên bản Java từ lỗi `UnsupportedClassVersionError` khi khởi chạy (`JavaRuntime.extract_required_java_major`)**:
  - Nếu game gặp lỗi khởi động `UnsupportedClassVersionError`, bộ phục hồi Java (`MinecraftExecutor._start_with_java_recovery`) tự động phân tích log lỗi và chuyển sang runtime Java cao hơn đáp ứng yêu cầu.

### 2. Bảo vệ toàn vẹn màn hình khởi động (`StartupSplash`)
- Bọc bảo vệ `try ... except RuntimeError` tại các phương thức cập nhật giao diện (`update_progress`, `retranslate`, `show_error`, `_complete_finish`) để tránh lỗi truy cập đối tượng Qt/C++ đã bị giải phóng khi cửa sổ splash đóng sớm.

### 3. Tối ưu hóa Cơ sở dữ liệu Tài khoản, Microsoft OAuth & RPC Sidecar
- **Tối ưu kết nối SQLite (`AccountDatabase.connect`)**:
  - Lưu chữ ký kiểm tra DB `(resolved_path, file_size)` trong bộ nhớ để bỏ qua việc chạy lặp lại `PRAGMA quick_check` và kiểm tra schema DDL ở mọi lần mở kết nối mới.
- **Đảm bảo thứ tự khởi tạo cổng trong `MicrosoftOAuth`**:
  - Bind và lắng nghe cổng `127.0.0.1:8400` trên `OAuthCallbackServer` trước khi mở trình duyệt đăng nhập Microsoft, loại bỏ race condition khi trình duyệt phản hồi tức thì.
- **Chống deadlock & Bảo vệ luồng JSON-RPC (`CoreRpcClient` & `StdioRpcServer`)**:
  - Chuyển `stderr` của tiến trình sidecar sang `subprocess.DEVNULL` để tránh deadlock khi đầy pipe 64KB, và điều hướng `sys.stdout` của tiến trình stdio server sang `sys.stderr` để ngăn thư viện ngoài làm hỏng luồng JSON-RPC.
