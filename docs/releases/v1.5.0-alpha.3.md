# MCW Launcher v1.5.0-alpha.3

Ngày phát hành source: 2026-08-22

Alpha 3 đưa launcher từ một bản Vanilla Linux smoke test sang nền tảng thử nghiệm desktop Linux đầy đủ hơn. Release gate gồm Vanilla, Fabric, Quilt, Microsoft OAuth, XDG storage và quản lý đúng cây tiến trình Minecraft.

## Điểm mới

- Dữ liệu Linux dùng XDG thay vì ghi cạnh source.
- Migration Alpha 2 theo nguyên tắc copy-only, atomic và không ghi đè xung đột.
- Microsoft credential ưu tiên Linux Secret Service thông qua keyring.
- OAuth có fallback `xdg-open`; callback chỉ lắng nghe tại `127.0.0.1:8400`.
- Mỗi phiên Minecraft dùng process group riêng trên Linux.
- Thanh điều hướng luôn hiển thị trạng thái Online, Offline hoặc Checking.
- Fabric và Quilt được đưa vào checklist smoke test Lubuntu.

## Nâng cấp từ Alpha 2

Nếu giải nén Alpha 3 đè lên cùng thư mục Alpha 2, launcher tự tìm dữ liệu portable cạnh source. Nếu dùng thư mục mới, chạy lần đầu với:

```bash
MCW_LEGACY_ROOT="/duong/dan/toi/mcw-launcher-v1.5.0-alpha.2" python launcher.py
```

Dữ liệu nguồn không bị xóa. Chỉ xóa bản Alpha 2 sau khi kiểm tra instance, account, theme và managed Java trong Alpha 3.

## Release gate

- Windows 10/11 x64: full automated regression.
- Lubuntu 24.04 x64: launcher startup, Vanilla, Fabric, Quilt, Microsoft login, cached offline launch và Stop/Kill.
- Không phát hành standalone `mcw-launcher-core` trong bước này.

## Giới hạn

- Chưa có AppImage, `.deb` hoặc updater Linux.
- Forge/NeoForge chưa phải release gate Linux.
- Linux ARM64 chưa được smoke-test thực tế.
