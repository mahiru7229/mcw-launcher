# MCW Launcher v1.5.0-alpha.1

Alpha 1 mở đầu đợt refactor của nhánh 1.5 trên nền source v1.4.1. Mục tiêu của bản này là làm sạch repository, giảm side effect khi startup và đặt biên nền tảng cần thiết cho Linux.

## Thay đổi chính

- Dọn file patch/delivery/test output và module rỗng hoặc không còn consumer.
- Chuẩn hóa README, project metadata, changelog, contributing và security policy.
- Version metadata chỉ tải khi operation yêu cầu; không request mạng trong lúc import.
- Version JSON dùng checksum verification và verified-cache fallback.
- Validate metadata path, identifier và SHA-1 trước khi tạo download target.
- Native library selection theo Windows/Linux/macOS rule; nhận diện x86, x64 và ARM64 rõ ràng.
- Thêm Linux vào CI test matrix.

## Giới hạn đã biết

- Alpha 1 chưa cung cấp Linux binary.
- Managed Java download/extraction và một số OS integration còn thiên về Windows.
- Cần smoke test thực tế trên Lubuntu trước khi nâng trạng thái Linux.

## Checklist tester

1. Sao lưu `instances/` và `accounts/`.
2. Khởi động launcher trong môi trường sạch và khi offline.
3. Tạo Vanilla instance, tải game, launch và thoát game.
4. Kiểm tra Fabric/Forge instance và native extraction trên OS đang dùng.
5. Xuất diagnostics bundle và xác nhận không lộ token/đường dẫn cá nhân.
6. Ghi rõ OS, architecture, Python và Java trong bug report.
