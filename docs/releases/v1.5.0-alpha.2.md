# MCW Launcher v1.5.0-alpha.2

Alpha 2 tập trung đưa launcher vào vòng kiểm thử thực tế trên Lubuntu và chuẩn hóa các ô lựa chọn trong GUI.

## Linux bring-up

- Thêm platform profile dùng chung cho Windows/Linux và x64/ARM64.
- Adoptium chọn đúng OS/architecture và package `.tar.gz` trên Linux.
- Java extractor hỗ trợ ZIP/TAR.GZ, path validation, safe symlink và executable permission.
- Java discovery dùng `JAVA_HOME`, `PATH` và managed runtime đúng quy ước Linux.
- Credential encryption có backend local dành cho Linux khi Windows DPAPI không tồn tại.
- Bổ sung SOCKS proxy dependency cho môi trường có proxy hệ thống.
- Thêm `tools/linux_preflight.py` và tài liệu test Lubuntu.
- Dùng cache manifest và version metadata đã xác minh trước khi thực hiện request mạng.
- Quét Java local ngay khi startup; chỉ kiểm tra JDK release online sau khi xác nhận có mạng.
- Cảnh báo rõ chế độ offline, bỏ qua auto-update và tự làm mới metadata khi kết nối trở lại.

## UI

- Mọi `QComboBox` được quản lý bởi một adaptive sizing component dùng chung.
- Chiều rộng cập nhật theo mục đang chọn, font, theme, language và model data.
- Chiều rộng control/popup bị giới hạn theo parent và màn hình để không phá layout.
- Nội dung vượt giới hạn dùng tooltip thay vì kéo giãn cửa sổ.

## Kiểm thử

- 1.603 core test đạt trên Python 3.12/Linux.
- Adoptium Linux Java 21 metadata được xác minh trực tiếp.
- GUI test cần Qt system libraries và được chạy trong Ubuntu CI/Lubuntu VM.
- Launcher và Vanilla Minecraft 1.21.1 đã mở thành công trên Lubuntu 24.04 trong VirtualBox.
- Cached offline launch đã được xác nhận: mất mạng không ngăn game khởi động.

## Release gate

Alpha 2 đã đạt mục tiêu: Lubuntu mở launcher, load manifest, tạo offline Vanilla instance, tự provision Java và vào được menu chính Minecraft. Linux vẫn ở mức alpha vì chưa có binary installer và chưa hoàn tất regression cho mọi mod loader.
