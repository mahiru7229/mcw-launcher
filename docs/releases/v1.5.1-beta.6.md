# MCW Launcher v1.5.1-beta.6

Beta 6 focuses on the remaining Windows self-update `WinError 5` seen in live Beta 5 logs.

## Windows updater

- The updater no longer treats `CreateFile(DELETE)` as proof that `MCW Launcher.exe` can be replaced.
- The definitive transition uses `ReplaceFileW`, then `MoveFileExW(REPLACE_EXISTING)`.
- If direct replacement is blocked by access/sharing/lock errors, the updater attempts a rename-away fallback: move the old image into the updater recovery directory, then install the new image at the original launcher path.
- The old retired image is deleted when possible; if Windows still references it, cleanup is scheduled for reboot when supported.
- READONLY is cleared before the transition and restored on a failed transition.
- Logs include the native Win32 error code and message.

## Safety

The rollback backup is still created before the executable transition. If the new launcher cannot be placed after rename-away, the updater immediately restores the previous pathname and aborts before copying the remaining release files.

## Validation target

The critical live migration is `v1.5.1-beta.5 -> v1.5.1-beta.6` on Windows. The updater log should show either a successful direct native replacement or `using Windows rename-away fallback`, followed by successful installation and restart without `WinError 5`.
