# MCW Launcher v1.5.0

v1.5.0 là bản Stable đầu tiên phát hành đồng thời cho Windows x64 và Linux x64. Bản Stable giữ nguyên runtime đã vượt qua smoke-test Beta 4 và chỉ chuyển metadata/kênh cập nhật sang Stable.

## Điểm chính

- Quản lý instance Vanilla, Fabric, Quilt, Forge và NeoForge.
- Tự chọn và quản lý Java phù hợp theo phiên bản Minecraft/mod loader.
- XDG storage, Microsoft login, Secret Service và giám sát process group trên Linux.
- Automatic updater có xác minh checksum, backup, rollback và khởi động lại trên Windows/Linux.
- Responsive UI giữ kích thước tự nhiên; nội dung dùng thanh cuộn khi cửa sổ nhỏ.
- Open Folder hoạt động trong bản Linux PyInstaller qua `xdg-open`, `gio` hoặc file manager phù hợp.

## Release gate

1. Toàn bộ test Windows và Ubuntu phải đạt trước khi build.
2. GitHub Actions build hai ZIP native `windows-x64` và `linux-x64` rồi kiểm tra SHA-256.
3. Vanilla/Fabric/Quilt/Forge/NeoForge, Microsoft login, offline cache, Stop/Kill và persistence đã được kiểm thử trên Lubuntu trong chuỗi Alpha/Beta.
4. Automatic update Linux đã được xác nhận bằng cập nhật thực tế giữa hai bản Beta.
5. Responsive OptiFine/Instance Info và Open Folder Linux đã được xác nhận lại ở Beta 4.

## Nâng cấp

- Người dùng Beta 4 có thể cập nhật lên Stable bằng updater hoặc giải nén ZIP Stable vào một thư mục mới.
- Dữ liệu account, instance, runtime, cache và settings vẫn nằm trong các thư mục XDG hiện tại trên Linux.
- Không đánh dấu GitHub Release `v1.5.0` là pre-release.

## Giới hạn

- Chưa cung cấp AppImage, `.deb`, Linux ARM64 hoặc macOS.
- MCW Core vẫn được bundle cùng launcher; chưa phát hành wheel/source archive độc lập.
