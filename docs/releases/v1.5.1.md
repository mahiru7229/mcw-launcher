# MCW Launcher v1.5.1

MCW Launcher v1.5.1 is the stable release promoted from the 1.5.1 beta series.

## Highlights

- Hardened updater architecture with a dedicated updater from the incoming release.
- Windows native launcher replacement with rename-away fallback and rollback protection.
- Fabric `provides` alias support in dependency resolution, including nested JARs.
- Release packages no longer bundle the development `docs/` directory; old bundled docs are cleaned during update.
- MCW Update Bridge v1.6.0 provides a one-time recovery route from affected v1.5.0 installations directly to v1.5.1.

## Upgrading from v1.5.0

The updater shipped in v1.5.0 can fail with WinError 5 while replacing `MCW Launcher.exe`. If that happens, download the platform-specific MCW Update Bridge v1.6.0 attached to this release, verify its SHA-256 sidecar, close MCW Launcher, run the Bridge, and select the existing launcher folder. The Bridge installs v1.5.1 without relying on v1.5.0 updater code.

Do not enable the `MCW-USE-BRIDGE` release marker for normal stable publication. v1.5.0 predates automatic Bridge routing; users on newer releases should continue using the normal bundled updater.
