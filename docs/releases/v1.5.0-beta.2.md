# MCW Launcher v1.5.0-beta.2

Beta 2 là live-update gate đầu tiên cho gói Linux x64 và hoàn thiện các lỗi desktop được phát hiện khi smoke-test Beta 1 trên Lubuntu.

## Điểm chính

- Kiểm tra cập nhật trực tiếp từ Beta 1 sang Beta 2 bằng GitHub Release ZIP.
- OptiFine dialog cuộn phần nội dung khi thiếu chiều cao; hàng action luôn cố định.
- Instance Info giữ kích thước tự nhiên và cuộn dọc ở cửa sổ nhỏ.
- Open Folder trên Linux ưu tiên `xdg-open`, fallback sang `gio open` và Qt.
- Windows vẫn dùng Qt desktop handler và được giữ trong regression gate.

## Gate cần xác nhận trên Lubuntu

1. Beta 1 phát hiện Beta 2, tải đúng asset `linux-x64` và xác minh SHA-256.
2. Launcher tự đóng, thay file, giữ executable mode rồi mở lại ở `v1.5.0-beta.2`.
3. Account, instance, world, settings và runtime XDG còn nguyên.
4. Open Folder mở đúng file manager từ mọi điểm vào chính.
5. OptiFine và Instance Info không cắt/chồng nội dung ở màn hình nhỏ.

## Giới hạn

- Chưa có AppImage hoặc DEB.
- Linux ARM64 chưa nằm trong release gate.
- Cần giữ ZIP Beta 1 cho rollback thủ công trong lần test updater đầu tiên.
