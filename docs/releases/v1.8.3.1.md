# MCW Launcher v1.8.3.1

Bản cập nhật nóng đầu tiên (**Hotfix 1 - v1.8.3.1**) cho bản phát hành chính thức MCW Launcher v1.8.3 mang đến kiến trúc cập nhật trực tiếp từ Cloudflare Edge CDN với cơ chế dự phòng GitHub thông minh, sửa lỗi kết nối Signal cho Lazy Dialogs, hỗ trợ kênh Beta/Dev cho ATLauncher và tăng tốc nạp danh sách modpack FTB:

---

## Các thay đổi và khắc phục trong v1.8.3.1

### 1. Phân phối cập nhật qua Cloudflare Edge CDN & Tự động dự phòng GitHub
- **Cập nhật không bị giới hạn Rate Limit**:
  - Tích hợp `CloudflareReleaseClient` truy vấn danh sách bản phát hành từ API / Edge CDN (`mcw-download.pages.dev/releases/manifest.json`), giải quyết triệt để nguy cơ bị giới hạn lượt gọi API (HTTP 403 / 429) của GitHub.
- **Cơ chế chuyển nguồn dự phòng thông minh (Dual-Source Failover)**:
  - `UpdateManager` mặc định ưu tiên kiểm tra phiên bản qua Cloudflare Edge CDN.
  - Tự động chuyển vùng dự phòng sang GitHub API nếu CDN không khả dụng hoặc trả về lỗi.
  - Ngược lại, nếu chọn nguồn GitHub mà bị rate limit, launcher tự động kích hoạt CDN để không làm gián đoạn trải nghiệm người dùng.
- **Hỗ trợ đa Mirror tải file cập nhật**:
  - `ReleaseAsset` bổ sung danh sách `mirror_urls`. Trình tải cập nhật tự động thử tải từ CDN; nếu lỗi sẽ chuyển tiếp ngay lập tức sang GitHub release asset.
- **Cấu hình nguồn linh hoạt**:
  - Cho phép người dùng tùy chọn nguồn cập nhật trong cài đặt: Cloudflare CDN, GitHub, hoặc Tự động.

### 2. Khắc phục lỗi kết nối Signal đa tham số cho Lazy Dialogs (MainWindow)
- **Sửa lỗi `TypeError` cắt tham số trong PySide6**:
  - Sửa các kết nối `lambda` đơn tham số sang `lambda *args:` cho các controller: `FTBController`, `ATLauncherController`, `ContentPackController`, và `OptiFineController`.
  - Khắc phục triệt để hiện tượng PySide6 cắt bỏ tham số thứ 2 và thứ 3 (`project_details_changed`, `versions_changed`, `version_details_changed`, `entries_changed`, `state_ready`).
  - Chấm dứt hiện tượng hộp thoại FTB và ATLauncher bị kẹt vĩnh viễn ở trạng thái `"Loading versions..."` khi chọn modpack, lỗi nạp Resource/Shader pack và lỗi mở OptiFine Dialog.

### 3. Hỗ trợ kênh Beta/Dev & Sắp xếp ổn định Version cho ATLauncher
- **Đọc và phân giải `devVersions`**:
  - `ATLauncherClient._parse_pack` đọc toàn diện mảng `devVersions` (gán cờ `development=True`) từ ATLauncher V1 API.
  - Cho phép người dùng xem và cài đặt đầy đủ các bản thử nghiệm (Alpha/Beta) khi bật tùy chọn Include Beta/Alpha.
- **Sắp xếp thứ tự Version ổn định (Stable tie-breaker)**:
  - Áp dụng tie-breaker chỉ mục xuất hiện gốc `(-index)` trong `ATLauncherClient._parse_pack`, `ATLauncherClient.list_versions` và `ATLauncherBrowserDialog.set_versions`.
  - Bảo toàn nguyên vẹn thứ tự phiên bản mới nhất trước (newest-first) từ API khi dữ liệu CDN thiếu timestamp `published` / `updated`, loại bỏ sai lệch do so sánh chuỗi số phiên bản.

### 4. Triệt tiêu xung đột tác vụ mạng & Tăng tốc nạp FTB gấp 5 lần
- **Phân nhóm tác vụ mạng (Network Task Grouping)**:
  - Bổ sung tham số `group` cho `BaseController._run_network_task`, phân nhóm rành mạch: `ftb.details`, `ftb.versions`, `ftb.version`, `atlauncher.details`, `atlauncher.versions`, `atlauncher.version`.
  - Khi người dùng click chuyển nhanh giữa các pack hoặc version, tác vụ cũ được tự động hủy hợp tác (`REPLACE`) thay vì xếp chồng làm treo hoặc khóa cứng giao diện (`set_busy(True)`).
- **Tải song song có kiểm soát trong `FTBClient.search_projects`**:
  - Sử dụng `ThreadPoolExecutor` (tối đa 6 workers) để phân giải thông tin chi tiết các modpack thiếu ID song song, rút ngắn thời gian tìm kiếm và làm mới danh sách FTB từ 5–15 giây xuống chỉ còn ~1–2 giây.
