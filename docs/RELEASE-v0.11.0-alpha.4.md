# MCW Launcher v0.11.0-alpha.4 — Interactive Motion

## Tiếng Việt

Alpha 4 đưa Theme Animation Engine vào các tương tác hằng ngày của launcher.

### Thay đổi chính

- Thêm theme schema 4 với block `motion` được kiểm tra an toàn.
- Chuyển trang có fade, slide hoặc fade-slide do theme cấu hình.
- Button có animation hover và pressed nhẹ, tương thích PNG/CSS theme.
- Sidebar có thể thu gọn thành icon-only và mở rộng bằng animation.
- Dialog có fade-in theo theme.
- Cancel trong Launch Control xuất hiện/biến mất mượt hơn; badge trạng thái có feedback khi đổi state.
- Thêm chế độ `Full`, `Reduced`, `Off` trong Launcher Settings.
- Theme schema 1–3 vẫn hoạt động và tự dùng motion fallback.

## English

Alpha 4 applies the Theme Animation Engine to everyday launcher interaction.

### Main changes

- Adds validated theme schema 4 `motion` configuration.
- Adds theme-driven fade, slide, and fade-slide page transitions.
- Adds subtle hover and pressed animation for themed buttons.
- Adds an animated icon-only collapsible sidebar.
- Adds theme-driven dialog fade-in.
- Smoothly reveals/hides Launch Control cancel actions and provides state-change feedback.
- Adds `Full`, `Reduced`, and `Off` motion modes.
- Keeps schema 1–3 themes compatible through safe defaults.
